# Политика конфиденциальности

«Транскрибатор: речь в текст» для Android (`ru.transcrib.app`), версия 1.1.1. Разработчик — Алина Катаева.

## Записи и расшифровки

Приложение обрабатывает выбранные аудио и видео на устройстве. Микрофон используется для записи через встроенный диктофон. Для распознавания речи, расстановки знаков препинания и разделения реплик по спикерам интернет не нужен. Записи и тексты расшифровок не отправляются разработчику или в рекламную систему.

Записи и расшифровки хранятся в памяти приложения. Их можно удалить в приложении. Экспортированные файлы остаются в выбранной папке, и их можно удалить отдельно. Если вы отправите файл через «Поделиться», его обработка в другом приложении зависит от правил этого приложения.

## Реклама

Приложение использует Yandex Mobile Ads SDK для загрузки и показа рекламы. Для этого SDK подключается к сервисам Яндекса. При наличии необходимых разрешений и в зависимости от настроек устройства SDK может передавать Яндексу рекламный или другой идентификатор устройства. Яндекс использует такие данные для подбора рекламы и оценки её эффективности.

В сборку также входит библиотека AppMetrica. Если отправка статистики включена, библиотека может передавать Яндексу технические сведения о приложении и устройстве, данные о работе приложения и идентификаторы. Подробности описаны в [документации AppMetrica](https://appmetrica.yandex.com/docs/ru/data-security/google-data-safety).

Подробнее о том, как Яндекс обрабатывает данные, см. в [политике конфиденциальности Яндекса](https://yandex.ru/legal/confidential/ru/) и [документации рекламного SDK](https://ads.yandex.com/helpcenter/ru/dev/android/app-privacy-android). Настроить использование рекламного идентификатора можно в настройках Android.
