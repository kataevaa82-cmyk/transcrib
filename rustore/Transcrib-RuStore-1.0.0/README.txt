2. СОДЕРЖИМОЕ ПАПОК

01_texts/            тексты карточки, по файлу на поле консоли
02_icon/             иконка для карточки: 512×512 PNG, фон без прозрачности
03_logos/            логотипы для сайта, соцсетей, статей и баннеров:
                       transcrib-icon.svg / -1024.png          квадратная иконка
                       transcrib-icon-rounded.svg / .png       иконка со скруглёнными углами
                       transcrib-logo.svg / .png               иконка + надпись, для светлого фона
                       transcrib-logo-white.svg / .png         иконка + надпись, для тёмного фона
04_screenshots/      скриншоты с подписями, 1080×1920 JPG
  no-frame/          те же экраны без подписей и фона
05_promo/            промо-баннер 16:9 (1920×1080 и 3840×2160). В карточке RuStore это
                     необязательное поле — пригодится для обложки видео, продвижения и блога
06_privacy_policy/   политика конфиденциальности: .html для размещения, .md и .txt — исходник


3. ЧТО СДЕЛАТЬ ВРУЧНУЮ ПЕРЕД ПУБЛИКАЦИЕЙ

[ ] Указать e-mail поддержки вместо «<УКАЖИТЕ E-MAIL>» в 01_texts/09_contacts.txt
    и в политике конфиденциальности (06_privacy_policy — все три файла).
[ ] Разместить privacy-policy.html по публичной ссылке (свой сайт, GitHub Pages,
    Яндекс Диск / Облако Mail.ru с публичным доступом) и указать ссылку в консоли.
[ ] Проверить, что название «Транскрибатор: речь в текст» не занято. Запасные
    варианты — в 01_texts/05_tags_category_age.txt.
[ ] Выбрать категорию и теги из списка консоли (рекомендации — в том же файле).
[ ] По желанию: добавить видео с VK Видео (публичное, 1–2 минуты).
[ ] Загрузить APK (Transcrib-1.0.0.apk), подписанный ключом release-key/transcrib-release.jks.
    Этот ключ нужен для всех будущих обновлений — храните его копию отдельно.


4. ПРО РАЗМЕР APK
